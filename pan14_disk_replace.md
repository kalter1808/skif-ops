## Замена дисков в блейдах Panasas 14

> **Важно:** не перепутайте диски:
>
> - `adY` — старый исправный диск с рабочей разметкой;
> - `adZ` — новый пустой диск.

### 1. Сохранение информации

Сделайте скриншот информации о текущем статусе блейда.

Особенно важно зафиксировать:

- какой диск вышел из строя;
- какой диск остался исправным.

### 2. Выключение блейда

Выполните:

```text
Halt node
```

Дождитесь полного выключения блейда.

### 3. Извлечение дисков

Извлеките блейд и достаньте диски.

### 4. Подготовка новых дисков

Подключите к отдельному компьютеру:

- SSD с системой;
- старый исправный диск — `adY`;
- новый диск — `adZ`.

Загрузитесь с SSD:

```text
ufs:/dev/ad4s2
```

Войдите под пользователем `root`.

#### Определение дисков

Посмотрите список дисков и разделов:

```sh
gpart show
```

Найдите старый исправный диск с разметкой. На нём должно быть пять разделов. Далее этот диск обозначается как `adY`.

Просмотрите устройства и найдите новый диск:

```sh
ls /dev
```

У нового диска не должно быть разделов. Далее он обозначается как `adZ`.

#### Очистка нового диска

Если новый диск не пустой, удалите с него существующую разметку:

```sh
gpart destroy -F /dev/adZ
```

> **Осторожно:** перед выполнением команды убедитесь, что `adZ` — именно новый диск.

#### Перенос разметки

Перенесите разметку со старого диска на новый:

```sh
gpart backup adY | gpart restore adZ
```

Установите загрузочный код:

```sh
gpart bootcode -b /boot/pmbr -p /boot/gptboot -i 1 adZ
```

Проверьте результат:

```sh
gpart show
```

#### Настройка `gmirror`

Добавьте рабочий системный раздел старого диска в `gmirror`:

```sh
gmirror label -v gm0 /dev/adYp2
```

Добавьте рабочий раздел `swap` старого диска в `gmirror`:

```sh
gmirror label -v gm1 /dev/adYp3
```

Проверьте состояние зеркал:

```sh
gmirror status
```

Загрузите модуль `gmirror`:

```sh
gmirror load
```

Снова проверьте состояние:

```sh
gmirror status
```

Зеркала `gm0` и `gm1` должны появиться.

Добавьте системный раздел нового диска в зеркало:

```sh
gmirror insert gm0 /dev/adZp2
```

Добавьте раздел `swap` нового диска в зеркало:

```sh
gmirror insert gm1 /dev/adZp3
```

Проверьте состояние синхронизации:

```sh
gmirror status
```

Должна начаться синхронизация.

#### Замена второго диска

После завершения синхронизации:

1. Выключите компьютер.
2. Извлеките старый диск.
3. Вместо него подключите второй новый диск.
4. Повторите процедуру копирования разметки и синхронизации.

> **Критически важно:** на каждом этапе проверяйте назначение дисков. `adY` — диск с рабочей разметкой, `adZ` — новый диск.

### 5. Проверка блокировки системы

Проверьте, что в административном интерфейсе всех Panasas включён параметр:

```text
Lock system
```

Без этой настройки блейд может подключиться к другой системе Panasas.

### 6. Инициализация блейда

1. Установите блейд обратно.
2. Откройте настройки блейда.
3. Запустите:

```text
Reinit node
```

> **Критически важно:** не перепутайте `Reinit node` с `Reinitialize system` в интерфейсе самого Panasas. Команда `Reinitialize system` может привести к потере данных или полной переинициализации системы.
